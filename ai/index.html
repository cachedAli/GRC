One choke point

How one AI call travels. The same path for every feature that calls a model through the platform: the order below is the order in the code.

  1. 01A registered feature asksIt declares which record columns it may see. People become aliases, money becomes a band; a new column is never sent until it is classified.
  2. 02Licence screenSecure Controls Framework text is screened out of every prompt.
  3. 03Model tierLight, standard or deep. Each deployment can send light and deep work to different models.
  4. 04Data-protection gatewaySecrets and account numbers removed; names, e-mails, hosts and IPs swapped for placeholders. If the check fails, the call is refused.
  5. 05Leading AI modelsOnly the masked prompt reaches the model. Six use cases can answer an identical request from a cache instead.
  6. 06The answer, restoredPlaceholders are put back, so you read real names. Removed values never come back.
  7. 07A row in your ledgerWho asked, which feature, tokens, cost and status, in your tenant’s own usage log.

Where the path differs. Eight registered use cases do not pass through the gateway today, one optional path in the AI risk assessment among them. What the gateway does

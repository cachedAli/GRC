# Reference-site analysis

## References

Analysed six internal prototype pages, six live external homepages and the supplied Drata/Secureframe mega-menu screenshots. Detailed external and visual findings: `23-external-reference-site-analysis.md`, `25-screenshot-visual-analysis.md`.

| Reference | Narrative | Trust | Conversion | Lesson for CompliVerse |
|---|---|---|---|---|
| Secureframe | outcome → pillars → products → frameworks → proof | customers, experts, stories | demo | clear family grouping and whitespace |
| Scrut | AI promise → proof → stages → AI roles → product pillars | reviews, metrics, stories | demo/AI tour | explain AI by task, not adjective |
| Drata | platform → use cases → AI → proof | customer and quantified outcomes | get started/contact | systematic mega-menu, but too dense for launch |
| Vanta | trust thesis → product jobs → AI → frameworks → segments | logos, outcomes, analyst | email/demo | progressive disclosure |
| LogicGate | enterprise platform → applications → features → integrations/services | analysts, ROI | demo | application-category structure |
| SwiftGRC | generic promise → features → frameworks → testimonials | vague claims | demo | avoid generic, unsubstantiated copy |
| Landing prototype | cinematic platform story | illustrative data | demo | useful narrative, not implementation proof |

No competitor wording, proof or visual identity should be copied.

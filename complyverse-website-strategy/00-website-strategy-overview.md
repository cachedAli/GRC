# Website strategy overview

## Product truth

CompliVerse is a tenant-aware GRC application connecting framework requirements, reusable controls, evidence, risk, governance documents, vendor risk and security-operation records. Confirmed users include compliance leaders, risk managers, security teams, auditors, control owners, approvers, administrators, employees and vendors. Evidence: `../complyverse-product-discovery/`.

## Primary workflow

`Select or upload framework → organize and map controls → assign work → collect and review evidence → connect risk/findings/actions → approve and report`

## Safe positioning

**Turn framework requirements into connected control, evidence and risk work.** Safe claims: framework/control hierarchy, normalized mappings, control workbench, evidence versions and packages, ERM/RCSA, governance lifecycle, vendor TPRA records, configurable workflow definitions. Partial claims requiring qualification: AI, integrations, discovery, continuous monitoring and calculations.

## Trust approach

Use real product screens, versioned framework catalog details, architecture explanations, permission models, example mappings, sample audit packages and guided tours. Do not invent customers, certifications, outcomes, awards, integrations or autonomous AI.

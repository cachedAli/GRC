# Platform page

## Page name

Platform overview

### Page purpose

Explain how product records connect.

### Main message

Frameworks, controls, evidence, risks, governance records, vendors, assets and reports form a connected tenant-aware model.

### Section order

1. **Follow the work, not disconnected registers.** Explain framework → control → evidence relationships.
2. **Make responsibilities visible.** Explain owners, reviewers, approvals, tasks and workflow instances.
3. **Keep evidence behind reporting.** Explain evidence versions, audit packages, history and report definitions.
4. **Configure repeatable review.** Explain workflow nodes, approvals, schedules and notifications with partial-status caveat.
5. **Use AI carefully.** Link to AI/security pages.
